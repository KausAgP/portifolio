Projeto 01

API de personagens e habilidades

Back-end

Problema

Um sistema precisa guardar dados que se relacionam entre si e controlar quem pode ver e alterar cada coisa.

O que eu fiz

Criei uma API REST com cadastro e login de usuários e rotas para criar, listar, editar e apagar os dados.

Como eu fiz

Node.js, Express e TypeScript. Prisma com MySQL para o banco, JWT para o login, bcrypt para as senhas e Zod para validar os dados.

Resultado

API com 7 recursos completos (caminhos, sequências, autoridades, habilidades, artefatos, personagens e goos), listas paginadas e rotas exclusivas para administradores.

Projeto 02

CRUD em React

Front-end

Problema

A API precisava de uma interface para que as pessoas pudessem usar os dados sem mexer no código.

O que eu fiz

Fiz o site em React com login, cadastro e telas para ver, criar, editar e apagar cada tipo de dado. Também tem uma página para montar um grupo de personagens.

Como eu fiz

React, Vite, React Router e CSS. O site se conecta à API por requisições HTTP e guarda o token de login no navegador.

Resultado

Site com várias páginas, rotas protegidas para administradores e telas de CRUD para os dados da API.
